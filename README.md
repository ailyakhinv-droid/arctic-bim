# Цифровой паспорт экспедиционного модуля • BIM Арктика

Веб-приложение для хакатона/воркшопа по макетированию и информационному моделированию арктических модульных станций.

Приложение позволяет школьникам и студентам оцифровать собственный физический макет из мастерской, привязать к нему инженерные элементы и выгрузить официальный цифровой паспорт макета со спецификацией оборудования.

## 🚀 Возможности
- **3D-конфигуратор модуля**: интерактивная 3D-модель (Three.js) с поддержкой различных компоновок (1 Блок, 2 в ряд, Сдвоенный, Углом «Г», 2 Этажа, П-Форма), переключением кровли (для просмотра интерьера), анимацией метели и выбором арктических цветов фасада.
- **Цифровой двойник по фото**: пошаговая загрузка реальных фотографий физического макета с автоматической оптимизацией размера.
- **Инженерные метки (BIM-точки)**: расстановка маркеров по дисциплинам (Архитектура, Отопление, Вентиляция, Водоснабжение, Канализация, Электроснабжение) с редактированием параметров, типов данных и единиц измерения.
- **Автоматический паспорт проекта**: генерация чистого инженерного паспорта со штампом, фотофиксацией и сгруппированной спецификацией по системам (готов к печати в PDF).
- **Сохранение и загрузка**: автосохранение в `localStorage` и экспорт/импорт проекта в `.json`.

## 🌐 Запуск онлайн (GitHub Pages)
Приложение полностью автономно и работает прямо в браузере без сервера и сборки:
1. Включите **GitHub Pages** в настройках репозитория (`Settings` → `Pages` → ветка `main` / root).
2. Сайт станет доступен по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 💻 Локальный запуск
Просто откройте файл `index.html` в любом современном браузере.
